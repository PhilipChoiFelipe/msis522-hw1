## Dataset

UCI *Individual Household Electric Power Consumption* — ~2.07M minute-level observations
from a single household in Sceaux, France (Dec 2006 – Nov 2010).

**Target:** `Global_active_power` (kW) — regression task

## Setup

### 1. Install dependencies

**On Apple Silicon (M1/M2) Mac:**
```bash
pip install tensorflow-macos==2.12.0 tensorflow-metal==0.8.0
pip install streamlit pandas numpy matplotlib seaborn scikit-learn xgboost shap joblib pyarrow
```

**On Linux / Intel Mac / Windows:**
```bash
pip install -r requirements.txt
# Replace tensorflow-macos with: pip install tensorflow
```

### 2. Place the raw data

Put `household_power_consumption.txt` in `../hw1_data/` relative to this folder
(i.e., `MSIS 522/hw1_data/household_power_consumption.txt`).

### 3. Train models (one-time)

```bash
cd hw1_power
python train_models.py
```

This takes ~10–15 minutes and saves all artifacts to `models/`.

### 4. Run the Streamlit app

```bash
streamlit run app.py
```

Then open [http://localhost:8501](http://localhost:8501) in your browser.

## Results Summary

| Model | MAE | RMSE | R² |
|-------|-----|------|----|
| Linear Regression | 0.0256 | 0.0393 | 0.9986 |
| Decision Tree | 0.0229 | 0.0448 | 0.9982 |
| Random Forest | 0.0228 | 0.0423 | 0.9984 |
| **XGBoost** | **0.0185** | **0.0350** | **0.9989** |
| MLP Neural Network | 0.0253 | 0.0375 | 0.9988 |

XGBoost is the best-performing model. SHAP analysis identifies `Global_intensity`,
`Sub_metering_3`, and `Global_reactive_power` as the top predictive features.
